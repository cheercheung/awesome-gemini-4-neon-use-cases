# Contributing

Open an issue or pull request with the original source of a Gemini 4 Neon
workflow, demo, integration, evaluation, or limitation. Describe the task,
Neon's role, the outcome, and the evidence that supports it.

For comparisons, identify the settings and harness when the source provides
them. Attribute performance, costs, and impressions to the source. Include
prompt text only when the original instruction is available and attributable.

Before opening a pull request, check the source and creator links, media
ownership, stable case identity, and every affected README language. See the
[maintenance guide](docs/maintenance.md) for the review process.
